# 🦅 عـشـة الـعـصـافـيـر (Bird Nest Tracker)

تطبيق ويب حديث ومتكامل ومخصص لمربي وهواة العصافير وطيور الزينة لإدارة ومتابعة السجلات الإنتاجية، تزاوج الأزواج، تواريخ وضع وفقس البيض الذكية، تتبع الزغاليل والشبابيات، وإدارة المصروفات والمبيعات مع مزامنة سحابية فورية عبر Supabase.

---

## ✨ المميزات الرئيسية:
- **سجل أزواج الإنتاج**: تتبع بيانات الذكر والأنثى، الأحجال (الدِبَل)، الطفرات، القفص، تواريخ التركيب وأسعار الشراء.
- **حسبة ذكية لمواعيد الفقس**: تنبيهات دقيقة لحساب مواعيد فقس كل بيضة بالتتابع الزمني الطبيعي (كل 48 ساعة).
- **سجل الزغاليل والشبابيات المستقلة**: تتبع إنتاج العشة المستقل حسب الحالة (فطام، شبابيات، معروض للبيع، تم البيع، للإنتاج) مع حساب العمر تلقائياً من تاريخ الفقس.
- **سجل المصروفات والتكاليف**: تصنيف شامل لجميع التكاليف (علف، أقفاص، بياضات، أدوية، مستلزمات) مع إدراج تكلفة شراء الأزواج تلقائياً.
- **سجل المبيعات والإيرادات**: تسجيل مبيعات الزغاليل والطيور والمستلزمات مع احتساب صافي الأرباح تلقائياً.
- **مزامنة سحابية فائقة (Supabase)**: دعم العمل دون اتصال (Offline / LocalStorage) مع مزامنة سحابية لحظية في أي وقت بين الهواتف وأجهزة الكمبيوتر.
- **تصميم متجاوب وتجربة مستخدم فاخرة**: واجهة عربية متناسقة تدعم الوضع الليلي والنهاري وتعمل بمرونة على مختلف مقاسات الشاشات.
